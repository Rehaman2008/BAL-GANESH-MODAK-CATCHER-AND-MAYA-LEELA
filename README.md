# 🐘 Bal Ganesh: Modak Catcher & Mooshak's Maya Leela

A 2D web-based game built with HTML5 Canvas, CSS3 animations, and Vanilla JavaScript with Web Audio API.

## 🎮 Game Overview

The game consists of two interconnected gameplay experiences:

### Phase 1: Divine Realm - Modak Catcher
* Guide Bal Ganesha across the temple floor using the mouse, keyboard arrows, or touch.
* Catch sacred modaks and laddus falling from the celestial skies while avoiding drops.
* Build combo multipliers and score points.
* **Target:** Score **3,000 Sacred Points** to unlock the sacred trial portal!

### Phase 2: Mooshak's Leela - Quest for Vinayaka
* Play as Mooshak the Mouse across **50 trials of platforms and obstacles**.
* Traverse crumbling tiles, moving lifts, lotus bouncers, and devil traps.
* Collect the **Sacred Modaks** on each level and reach the Golden Portal to advance.
* Real-time level selector and restart controls to return to the beginning intro.

---

## 🕹️ Controls

* **Modak Catcher:**
  * Left / Right Arrow Keys or Mouse / Touch to move Ganesha.
  * Pause button to pause/resume gameplay.

* **Maya Leela (Mooshak Platformer):**
  * `A` / `D` or `Left` / `Right Arrow`: Move Left / Right
  * `W`, `Up Arrow`, or `Spacebar`: Jump
  * On-screen touch buttons for mobile / tablet play.

---

## 🛠️ Built With

* **HTML5 Canvas** – 60 FPS graphics rendering and particle physics.
* **CSS3** – Divine glowing animations, temple atmosphere, and responsive HUD.
* **Vanilla JavaScript** – Pure ES6 game engine, state management, and collision detection.
* **Web Audio API** – Pure browser-synthesized audio (temple bells, chimes, jump sounds). Zero external audio dependencies.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).
3. Alternatively, run `start_server.bat` on Windows to serve via local HTTP on port 5500.
